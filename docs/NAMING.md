# Naming

| String | Use |
|---|---|
| Omahedron | Product name. Human-facing theme and plugin pack for stock Omarchy. |
| Hedronite | Org / company. |
| omahedron | Repo and flake name. Desktop-port tags used the prefix `omahedron-X.Y.Z` (last: `omahedron-4.0.3`). |
| `omahedron.themes.enable` | Opt-in Nix install of the theme directories. |
| Hedron / Hedron Light | Theme directory names: `hedron`, `hedron-light`. |
| omarchy-src | Archived-port flake input that vendors basecamp/omarchy. |
| nix-omarchy | Category descriptor in prose only. |
| Omarchanite | **Forbidden in this repo.** Other substrate, TBD. |
| Omarchy | Upstream desktop. Omahedron themes sit on top of it. |
| Omarchs | People who run Omarchy. The community's own word; use it for the audience, never as a product name. |
| Omachron | Name of the archived port's release schedule. Policy: [legacy/os-port/docs/CHANNELS.md](../legacy/os-port/docs/CHANNELS.md). |

The archived port's module options stayed `omarchy.enable`. The theme pack uses `omahedron.themes.enable`. Branding lives in the README and [brand/](brand/).

## Product mark

The Omahedron mark (lime and dark-green isometric cube on black) is Hedronite's product identity. Not an Omarchy or NixOS mark; separate from the Hedronite gold seal on hedronite.com. Files and usage: [brand/](brand/).
